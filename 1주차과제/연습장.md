# 📝 마크다운 실습 문서

마크다운(Markdown)은 서식 있는 텍스트를 손쉽게 작성할 수 있는 경량 마크업 언어입니다. 파일 확장자는 `.md`를 사용합니다.

---

## 1. 텍스트 강조 및 스타일

- **굵은 글씨 (Bold)**: `**내용**` 또는 `__내용__`
- *기울임 (Italic)*: `*내용*` 또는 `_내용_`
- ~~취소선 (Strikethrough)~~: `~~내용~~`
- `인라인 코드 (Inline Code)`: `` `코드` ``

---


## 2. 체크리스트 (할 일 목록)

- [X] 마크다운 가이드 읽기
- [X] 새 `.md` 파일 만들기
- [ ] 마크다운 문법 직접 수정해보기
- [ ] 미리보기 단축키로 결과 확인하기 (`Ctrl + Shift + V`)

---

## 3. 코드 블록 (Code Block)

언어명을 명시하면 구문 강조(Syntax Highlighting)가 적용됩니다.

```javascript
// 자바스크립트 예시
function calculateBMI(weight, heightCm) {
    const heightM = heightCm / 100;
    return (weight / (heightM * heightM)).toFixed(1);
}

console.log("BMI 결과:", calculateBMI(70, 175));
```

```python
# 파이썬 예시
def greet(name):
    return f"안녕하세요, {name}님!"

print(greet("사용자"))
```

---

## 4. 표 (Table)

| 항목   | 설명            | 기본 문법               |
| :----- | :-------------- | :---------------------- |
| 제목   | 헤더 표시       | `#`, `##`, `###`  |
| 목록   | 순서 없는 목록  | `-` 또는 `*`        |
| 링크   | 하이퍼링크 삽입 | `[텍스트](URL)`       |
| 이미지 | 이미지 표시     | `![설명](이미지경로)` |
